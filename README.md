# Dollar-Aligned CVaR-Logistic Regression for Consumer Credit Default

Yoni Aharon and Omry Bejerano

`final_project.ipynb` contains all the code (with outputs and figures)

## Data
Lending Club loan data (2007–2018), from Kaggle:
https://www.kaggle.com/datasets/wordsforthewise/lending-club

To run our code just download `accepted_2007_to_2018Q4.csv.gz` and update the path at the top of the
notebook (`DATA_PATH`), as it currently points to `/home/jupyter/lending_club/`
